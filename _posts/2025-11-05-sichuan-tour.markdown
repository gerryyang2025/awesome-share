# 九寨沟

* https://www.jiuzhai.com/about/jiuzhai-valley
* https://zh.wikipedia.org/wiki/%E4%B9%9D%E5%AF%A8%E6%B2%9F

## 简介

九寨沟位于四川省西北部岷山山脉南段的阿坝藏族羌族自治州九寨沟县漳扎镇境内，地处岷山南段弓杠岭的东北侧。距离成都市400多千米，系长江水系嘉陵江上游白水江源头的一条大支沟。九寨沟自然保护区地势南高北低，山谷深切，高差悬殊。北缘九寨沟口海拔仅2000米，中部峰岭均在4000米以上，南缘达4500米以上，主沟长30多公里。

九寨沟是世界自然遗产、国家重点风景名胜区、国家AAAAA级旅游景区、国家级自然保护区、国家地质公园、世界生物圈保护区网络，也是中国第一个以保护自然风景为主要目的的自然保护区。

九寨沟分三条沟：**日则沟、树正沟、则查洼沟3条主沟，呈倒Y形分布**。

**树正沟**自九寨沟景区大门至诺日朗瀑布，全长约13.8km，海拔约2500-2600米，共有海子（湖泊）40余个，约占九寨沟景区全部湖泊的40%。
火花海，犀牛海，老虎海，树正群海，树正瀑布，树正寨，卧龙海，双龙海，芦苇海，盆景滩

**日则沟**全长约25.3千米，位于诺日朗瀑布西南，海拔约2600-3100米，由北向南有镜海、珍珠滩、金铃海、五花海、熊猫海、箭竹海。
原始森林，天鹅海，芳草海，箭竹海，熊猫海瀑布，熊猫海，五花海，珍珠滩，珍珠滩瀑布，孔雀河道，镜海，诺日朗瀑布，五彩湖

**则查洼沟**全长约31.7千米，位于诺日朗瀑布东南，海拔约2600-3100米，由北向南有下季节海、上季节海、五彩池、长海。
长海，五彩池，上季节海，中季节海，下季节海，则查洼寨

## 九寨沟由来

九寨沟的得名来自于景区内九个藏族寨子（树正寨、则查洼寨、黑角寨、荷叶寨、盘亚寨、亚拉寨、尖盘寨、热西寨、郭都寨），这九个寨子又称为“和药九寨”。由于有九个寨子的藏民世代居住于此，故名为“九寨沟”。

世界自然遗产组织的官员，在1992年第一次到九寨沟考察时，从沟口进去时，大家被大雨蒙住了视线。当他们一行来到火花海景点时，天空突然放睛，阳光穿过空中的雾霭，在天空中画出了一道美丽的彩虹，妖娆艳丽的火花海呈现在这些世界级官员的眼前，他们被眼前的美景惊呆了。随即，他们俯下身跪在海子边上，向这大自然的造化叩拜。事后他们回忆说，这里的景色太美了，让他们太吃惊了。他们不曾想象过，大自然竟有如此的鬼斧神工，将中国的九寨沟点画得如天仙般的美丽。

他们的叩拜，是对大自然的敬仰；他们的叩拜，是感谢中国，为世界留下了一块瑰宝，为人间留住了一片仙境。


## 价值意义

九寨沟国家自然保护区是岷山山系大熊猫A种群的核心地和走廊带，具有典型的自然生态系统，为全国生物多样性保护的核心之一。

动植物资源丰富，具有极高的生态保护、科学研究和美学旅游价值。景区内生物多样性丰富，物种珍稀性突出。**九寨沟又是以高山湖泊群、瀑布、彩林、雪峰、蓝冰和藏族风情并称“九寨沟六绝”**，被世人誉为“童话世界”，号称“水景之王”。九寨沟还是以地质遗迹钙化湖泊、滩流、瀑布景观、岩溶水系统和森林生态系统为主要保护对象的国家地质公园，具有极高的科研价值。

# 四姑娘山 - 猫鼻梁

**猫鼻梁**是观赏四姑娘山全景的一个非常受欢迎的免费观景台，以其能欣赏四姑娘山四座主峰相连的壮丽景色而闻名。在猫鼻梁，可以清晰地看到四姑娘山的四座山峰一字排开。这里是拍摄四姑娘山全景和日照金山的绝佳地点。如果天气晴朗，傍晚时分有机会看到夕阳将雪山染成金黄的壮观景象。

# 四姑娘山 - 长坪沟

**长坪沟**位于四川省阿坝藏族羌族自治州小金县四姑娘山景区内，是四姑娘山"三沟"之一，以原始生态、徒步探险和雪山风光闻名。长坪沟全长约29公里，峽谷悠长，面积约100平方公里。**四姑娘山最高峰——幺妹峰（海拔6250米）就坐落于此**。

主要景点：

* **斯古拉寺（喇嘛寺）**：一座有着深厚历史的藏传佛教格鲁派寺院，是四姑娘山少有的人文景观，也是观赏四姑娘山的最佳位置之一。此地也是历代土司祭拜四姑娘山的地方。

* **枯树滩**：一片开阔的河床，砂石河滩上屹立着或卧倒着诸多枯树，形成一种沧桑的美感。据说这里是清乾隆年间大小金川战役的古战场遗址，枯树、碧水与蓝天构成独特画面。

* **虫虫脚瀑布**：一处数十米高的飞流，瀑布从半山腰飞泻而下。不过，前往瀑布观景台的栈道较为陡峭，需攀登约686级台阶。

* **上下干海子**：栈道的终点，也是长坪沟内推荐的露营地之一。

* **红石阵**：一大片壮观的红色石头群。这些石头因红色藻类生物密集生长于花岗岩上而呈现红色。

* **木骡子**：位于四姑娘山幺妹峰背后，是长坪沟内综合条件最好的露营地。这里草甸开阔、雪山环绕、溪流悠悠，像世外桃源一样。

# 四姑娘山 - 双桥沟

**四姑娘山双桥沟**以其便捷的观光体验和密集的雪山湖泊景观闻名，是四姑娘山景区中开发最成熟、最适合轻松游览的一条沟，拥有雪山、湖泊、森林、草甸、溪流等多层次景观。

> 双桥沟得名于当地老百姓为了通行方便在沟内搭建的两座木桥（一座由杨柳木搭建，俗称杨柳桥；另一座由红杉木搭建，俗称便桥）。沟内主要以雪峰、牧场、草地、森林等景观为主。

> 双桥沟内看不到四姑娘山的主峰，但可以看到很多其他美丽且壮观的山峰，例如猎人峰、鹰嘴岩、阿妣山等。

主要景点：

* **红杉林（沟尾）**：作为观光车的终点站，这里海拔约3840米。你可以漫步于红杉林栈道，欣赏周边雪山。

* **布达拉峰**：这座山峰因形似布达拉宫而得名。这里视野开阔，是拍摄雪山和公路大片的理想地点。

* **四姑娜措与隆珠措**：这两个都是双桥沟内的高山湖泊。四姑娜措传说是四姑娘沐浴的圣湖，湖水清澈，枯木老树静立，湖水中倒映着山体、雪峰。隆珠措的特色在于溪水中含有丰富的钙化物，沙棘树根部附积了大量钙质，从而死而不倒，成为双桥沟神话世界的一道靓丽风景。

* **撵鱼坝**：海拔约3500米，属半沼泽地。在这里，你可以选择轻松漫步穿过仪态万千的沙棘林，也可以体验高山漂流，感受"船在水上漂，人在画中行"的意境。

* **人参果坪（沟口附近）**：这是双桥沟冰川地貌的终点。这里有大片草甸，春夏季节，各种高山花卉布满草坪，景色优美。

# 黄河九曲第一湾 / 若尔盖大草原

**黄河九曲第一湾**位于四川省阿坝藏族羌族自治州若尔盖县唐克镇，是黄河在四川境内唯一的一段。这里以蜿蜒曲折的河流与壮美的高原风光闻名。

黄河九曲第一湾位于**四川省若尔盖县唐克镇**，地处四川、青海、甘肃三省交界处。黄河在此段流程中，为四川与甘肃之界河，河西为甘肃，河东为四川。**发源于巴颜喀拉山的黄河**，在此与白河汇合，形成了壮美曲折的"S"形河湾。

**傍晚是这里最美的时刻**。登上海拔接近4000米的观景台，能看到S形的黄河在夕阳下像一条血红的彩带，与满天的红霞相互映衬。很多摄影大片都诞生于此。

**若尔盖大草原**是由若尔盖、阿坝、红原、壤塘四县组成的高原草原，也是中国五大草原之一。这里地处黄河上游的大拐弯，是中国三大湿地之一，素有"川西北高原的绿洲"和"云端天堂"之称。





# 黄龙

**黄龙风景区**以其独特的**钙华景观**、丰富的自然生态和浓郁的民族文化，被誉为"人间瑶池"和"世界奇观"。

黄龙最引人注目的就是长达3.6公里的**黄龙沟**，沟内遍布乳黄色的**碳酸钙华沉积**，并呈梯田状排列，远望好似一条蜿蜒于密林幽谷中的**金色巨龙**，"黄龙"之名便由此而来。沟内形成了**3000余个**层层叠叠的彩池，池水因沉积物和光线折射，呈现出黄、绿、浅蓝、蔚蓝等变幻莫测的色彩。

黄龙风景区总面积广阔，植被茂密，森林覆盖率高达88.9%。这里生活着许多珍稀动物，包括**大熊猫**、**金丝猴**等。从山谷底部到山顶，你可以依次观赏到亚热带常绿与落叶阔叶混交林、针叶阔叶混交林、亚高山针叶林和高山灌丛草甸等丰富的垂直植被带。

黄龙所在的**松潘县**是一个多民族聚居地，生活着藏、羌、回、汉等民族。传承数百年的黄龙庙会将各族民俗文化荟萃一堂，届时你可以欣赏到跳锅庄、唱山歌、琵琶弹唱、吹羌笛等多姿多彩的民间艺术。
